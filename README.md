# 🌸 Iris Dataset Exploratory Data Analysis

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Iris dataset.

The goal is to analyze the dataset structure, identify patterns, check data quality, and visualize relationships between different features.

---

## 📂 Dataset

The Iris dataset contains information about three flower species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

### Features:

| Feature | Description |
|-|-|
| Sepal Length | Length of sepal |
| Sepal Width | Width of sepal |
| Petal Length | Length of petal |
| Petal Width | Width of petal |

---

## 📈 Key Insights

- Dataset contains 150 samples.
- No missing values were found.
- Petal features strongly differentiate flower species.
- Strong correlation exists between petal length and petal width.
